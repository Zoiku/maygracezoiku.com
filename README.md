# Maygrace Zoiku's Portfolio

A single-page personal website introducing Maygrace Zoiku and her work in leadership, accounting, and data analysis, including The Well Foundation.

## View locally

Clone this repository and open `index.html` in a browser. You can also serve the directory with a static web server.

The page contains its own styles and browser scripting. There is no package manifest, build step, application backend, or environment configuration.

## Editing and deployment

Update the biography, page sections, contact links, styles, and scripts in `index.html`. The document also contains the page title, description, and social-sharing metadata. Review the canonical destination metadata when changing domains.

Publish `index.html` to a static host. Google Fonts and externally linked resources require internet access.

## Checks

There is no automated test suite. Verify desktop and mobile layouts, navigation, interactive elements, and outbound/contact links after editing.
